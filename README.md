# Backpropagation Engine From Scratch

A scalar automatic differentiation engine built from scratch while learning the fundamentals of neural networks and backpropagation, inspired by Andrej Karpathy's micrograd.

## Features

- Computation graphs
- Forward propagation
- Backpropagation using the chain rule
- Gradient accumulation
- Topological sorting
- Basic mathematical operations
- `tanh` activation
- Finite-difference gradient checking

## Goal

Understand how automatic differentiation and backpropagation work internally instead of treating them as a black box.

## Status

Currently implemented as a scalar autograd engine. More neural-network functionality will be added as I progress through the course.
